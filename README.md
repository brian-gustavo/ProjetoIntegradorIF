# ProjetoIntegradorIF

Este é o software desenvolvido como projeto integrador do curso de Análise e Desenvolvimento de Sistemas (ADS) do IFSP-CJO, sendo que é empregada a linguagem de programação Python com o framework Django no back end e HTML/CSS/JS vanilla no front (utilizando o SSR do Django para criar as páginas), além de um banco de dados SQLite.

É um marketplace customer-to-customer (C2C) voltado para jogos, sejam eles físicos, digitais ou até mesmo de tabuleiro, em adição à quaisquer periféricos ou outros itens relacionados. Seu nome é MegaGame.

Para maiores detalhes, consulte o documento formal do projeto (docs/main.tex), que está disponível neste repositório.
